# 双动赋能双驱育心教学评估平台（轻量级 V2.1）

这是一个可直接在本机运行的**前后端分离轻量级平台**：后端为 Python 标准库 HTTP + SQLite，前端为无构建步骤的原生 HTML/CSS/JS。平台以当前 `report_generator/generate_report_dual.py` 的“即时—平均”双动态成绩逻辑为基础，按《双动赋能双驱育心SaaS平台技术设计与功能设计参数（轻量级V2.1）》实现了 MVP 一期“采集 → 计算 → 核定 → 发布 → 预警 → 育心留痕”闭环。

## 1. 快速启动

```powershell
# 在 D:\DDS 目录执行；平台本身不需要安装第三方依赖
python -m backend.main --host 127.0.0.1 --port 8000
```

浏览器打开：<http://127.0.0.1:8000>

首次启动自动创建 SQLite 数据库与演示账号：

| 角色 | 用户名 | 初始密码 | 用途 |
|---|---|---|---|
| 管理员 | `admin` | `admin123456` | 参数、审计、全量管理 |
| 教师 | `teacher` | `teacher123456` | 课程、导入、核定、发布、预警、转介 |
| 学生 | `student` | `student123456` | 绑定学号、查看已发布自身报告、量表、静默申请 |

> 登录后请立即在工作台修改密码。学生首次登录需输入“学号 + 姓名”绑定，姓名不一致会拒绝绑定。

## 2. 推荐使用流程

1. 教师登录 → **课程管理** → 新建课程。
2. **数据采集**：
   - 先导入“历史平均动态成绩”表（用于 ADG 时间加权），历史年份填写导出年份，如 `2025`；
   - 再导入雨课堂导出的原始工作簿，选择“即时过程数据”和评价日期；
   - 可用 `25药生`、`25营养` 等关键词筛选行政班/学号；
   - 平台会自动识别第一个“数据汇总”Sheet，并从表头提取满分、总页数、公告数等分母。
3. **报表闭环** → 选择课程与日期 → 计算 IDG / ADG。
4. 教师检查分子/分母证据与预警 → **教师核定** → **发布学生端**。
5. 在**预警中心**创建导航仪/救护车干预记录。
6. 在**量表与育心**中维护量表、审批静默申请、处理 2 小时心理转介工单。

### 学生如何查看已发布报告

1. 用学生账号登录。首次演示账号为 `student / student123456`。
2. 在“我的工作台”填写自己的**学号和姓名**完成绑定；姓名与教师导入数据不一致时会拒绝。
3. 进入“我的成长报告”，只能看到教师已发布报表中属于本人的一行。
4. “成长曲线”只显示自身基线与趋势，不显示班级排名。

若全班学生都需要独立访问，请管理员在“用户与角色”中为每个学生创建账号；建议登录名直接使用学号，并要求首次登录后修改密码。

标准 CSV 模板可在“数据采集”页面下载，包含有效页、有效交互、完整公告阅读、视频、防刷课停留时长等字段。

重复导入处理：

- 历史 IDG 表和即时表都有数据库唯一键，重复导入不会让同一学生同一日期被重复计入 ADG/IDG。
- “数据采集 → 导入记录”提供直接删除按钮。若删除的是重复导入，数据会自动挂到另一条同课程同类型记录；若删除唯一来源，则同步删除该次历史 IDG 或即时过程数据。

## 3. 已实现的核心设计

### 3.1 双动态成绩引擎

- 课程百分得分 = 学生实得分 ÷ 课程总分 × 100，范围 `[0,100]`。
- 课件阅读系数 = `(有效页 ÷ 总页) × 0.6 + (有效交互 ÷ 标准交互) × 0.4`，范围 `[0,1]`。
  - 若历史导出没有交互分母，则自动降级为有效页单因子，并在报表中标记“交互分母缺失”。
- 公告阅读系数 = 完整阅读公告条数 ÷ 公告总条数，范围 `[0,1]`。
- `IDG = 课程百分得分 × 课件阅读系数 × 公告阅读系数`。
- `ADG` 取时间窗口内最近三个周期，按近→远 `50% / 30% / 20%` 加权；不足三个周期时按可用权重归一化。
- 视频、互动为观测系数：只标红、不计入 IDG。

### 3.2 防刷课与防敷衍

- 单页平均停留 `< 5 秒`：有效页数不计入。
- `30 秒`内完成全部页面且页数完整：触发刷课标记，本周期课件系数归零。
- 公告阅读支持“停留秒数 + 图文加载完成”字段；未加载或停留不足 15 秒，不计完整阅读。
- 课件或公告任务未完成时标记“欠账不销”；全部补齐后显示欠账清偿。

### 3.3 数据适配与导入

- 雨课堂原始工作簿：自动选择“数据汇总”Sheet，第二行作为表头。
- 标准 CSV 模板：支持本平台完整字段，可用于其他平台接口降级导入。
- 历史 IDG 表：解析 `1001即时动态成绩`、`10月1日即时成绩`、完整日期等列名。
- 支持班级/学号筛选、文件上传留痕、导入警告、失败回滚。

### 3.4 三色、状态与预警

- 成绩三色：绿 `≥90`、蓝 `60–89.9`、红 `<60`。
- 系数预警：蓝 `<0.80`、红 `<0.50`，与成绩三色独立。
- 前置预警：系数连续 3 次低于 `0.80`，或较上期骤降超过 `0.30`。
- 状态分流：持续困难型、进步改善型、短期波动型、稳定达标型、成绩领跑型。

### 3.5 低利害铁律

- 后端未提供班级排名接口；教师表默认按班级与学号排序。
- 学生端只返回本人已发布报告。
- 导出必须确认低利害用途，并写入审计。
- 成长曲线强制带自身起点基线，只呈现趋势区间，不呈现位次。
- 系统参数中 `low_stakes_mode` 为常量，接口禁止关闭。

### 3.6 育心工作流

- 量表支持 Likert 选项、反向计分、危机触发规则。
- 量表结果只进入静默通道，不返回给学生分数，也不进入成绩报表。
- 危机触发自动创建 2 小时心理转介工单；超时自动升级。
- 学生可申请静默；教师审批后不再向其推送非必要公告提醒。
- 导入、核定、发布、撤回、导出、干预、转介均写审计。

### 3.7 干预与心理转介分工

- 预警中心同一学生多条系数/观测预警会合并为一行。
- 点击“登记干预”后，从下拉框选择标准类型：
  - 导航仪 · 学习提醒；
  - 导航仪 · 最小行动目标；
  - 导航仪 · 成长趋势反馈；
  - 救护车 · 教师一对一；
  - 救护车 · 心理辅导转介。
- 心理转介工单默认分派给当前登录教师，也可分派给其他教师/管理员。
- 被分派老师登录后可看到并处理自己的工单；管理员可看全部；未分派工单所有教师可见以便认领。
- 工单状态：`open` 未处理、`reported` 已上报、`completed` 已完成、`escalated` 超时升级。

## 4. API 概览

- 全部页面 `/`，静态资源 `/assets/*`。
- `/api/auth/*`：登录、当前用户、学号绑定、修改密码。
- `/api/courses`、`/api/imports`、`/api/reports*`。
- `/api/warnings`、`/api/students/{id}/growth`。
- `/api/questionnaires*`、`/api/silent-requests`、`/api/referrals`。
- `/api/settings`、`/api/audit`、`/api/template.csv`。
- `/api/users`：管理员创建账号、修改角色、停用/启用、重置密码。
- `/api/imports/{id}`：删除重复导入记录。

## 6. 与 V2.1 的对应关系与当前边界
