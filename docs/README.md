## 1. 平台入口

本机默认地址：

```text
http://127.0.0.1:8000
```

如果部署在服务器，请向学校管理员确认正式域名或 IP。

## 3. 一次完整教学评估闭环

```text
管理员创建教师账号
        ↓
教师创建课程
        ↓
导入历史 IDG 表
        ↓
导入即时过程数据
        ↓
生成双动态报表
        ↓
教师核定
        ↓
发布学生端
        ↓
学生查看本人成长报告
        ↓
教师根据预警开展导航仪/救护车干预
        ↓
必要时创建 2 小时心理转介工单
```

## 4. 使用原则

1. 数据权威源仍是雨课堂、学习通等教学平台；本系统负责采集、加工、评价与预警。
2. 评价结果默认低利害，不用于排名、评优、人事、薪酬或问责。
3. 学生只能查看本人已发布数据。
4. 心理量表结果只进入静默通道，不进入成绩，不向学生发布心理评价结果。
5. 心理危机处置主体是学校心理健康中心，本系统负责预警、转介和留痕。

## 5. 回归测试

开发或修改平台后建议执行：

```powershell
python tools\test_platform.py
python tools\integration_test.py
```

其中 `integration_test.py` 会使用临时数据库和临时端口，不影响当前运行数据，覆盖 V01–V07 验收项和主要业务闭环。
