# 管理员使用手册

适用角色：平台管理员、教务管理员  
适用版本：双动赋能双驱育心平台 轻量级 V2.1

## 1. 管理员职责

管理员负责：

1. 创建教师、学生、管理员账号；
2. 分配角色；
3. 重置密码；
4. 停用或启用账号；
5. 配置算法参数；
6. 查看审计；
7. 备份和恢复数据；
8. 平台安全运行。

管理员不应直接替代教师核定教学报表。

## 2. 登录

1. 打开平台地址。
2. 使用管理员账号登录。
3. 首次登录后立即修改初始密码。

> 不要把管理员账号借给他人使用。

## 3. 用户与角色

进入 **用户与角色**。

### 3.1 创建账号

| 字段 | 建议 |
|---|---|
| 姓名 | 真实姓名 |
| 登录账号 | 教师用工号，学生用学号 |
| 角色 | teacher / student / admin |
| 初始密码 | 至少 10 位，不建议使用生日 |

### 3.2 角色权限

| 角色 | 权限 |
|---|---|
| admin | 管理账号、参数、审计、全部工单 |
| teacher | 课程、导入、报表、核定、发布、预警、干预、量表 |
| student | 本人已发布报告、成长曲线、量表、静默申请 |

### 3.3 修改角色

在账号列表中修改角色后点击保存。

注意：

1. 管理员不能取消自己的管理员角色；
2. 管理员不能停用自己；
3. 角色变更写入审计。

### 3.4 重置密码

点击 **重置密码**，输入至少 10 位新密码。重置后要求用户首次登录立即修改密码。

## 4. 参数配置

进入 **参数配置**。

| 参数 | 默认 | 说明 |
|---|---:|---|
| 绿线 | 90 | 绿标阈值 |
| 蓝线 | 60 | 蓝标阈值 |
| 课件页权重 | 0.6 | 有效页因子 |
| 交互权重 | 0.4 | 有效交互因子 |
| ADG 窗口 | 42 天 | 历史周期范围 |
| IDG 周期 | 3 天 | 建议评价间隔 |
| 期末 IDG 占比 | 0.4 | 总评配置参考 |
| 系数蓝线 | 0.80 | 系数预警 |
| 系数红线 | 0.50 | 系数红区 |
| 单页最短停留 | 5 秒 | 防刷课 |
| 刷课判定 | 30 秒 | 全部页面过快完成 |
| 公告完整阅读 | 15 秒 | 防点开即关 |
| ADG 权重 | 50/30/20 | 近→远 |

低利害模式 `low_stakes_mode` 是制度常量，接口不允许关闭。

## 5. 审计留痕

进入 **审计留痕**。

可查看登录、导入、删除导入、生成报表、教师核定、发布、撤回、导出、参数修改、干预、心理转介和账号变更。

审计用于安全追溯，不得用于对学生进行额外评价。

## 6. 数据备份

轻量版数据主要在：

```text
D:\DDS\data\platform\dds.sqlite3
D:\DDS\data\platform\uploads
```

建议：

| 频率 | 建议 |
|---|---|
| 每天 | 自动备份数据库 |
| 每周 | 检查备份可恢复性 |
| 每学期 | 归档完整数据 |

备份时建议同时保存备份时间和版本说明。

## 7. 安全建议

1. 不在公开环境保存管理员密码；
2. 不共享账号；
3. 定期修改管理员密码；
4. 初始演示账号密码必须重置；
5. 仅在受控网络开放平台；
6. 正式部署应启用 HTTPS；
7. 定期查看异常登录和导出记录；
8. 心理相关数据访问应最小授权。

## 8. 常见管理员问题

| 问题 | 处理 |
|---|---|
| 教师忘记密码 | 用户与角色 → 重置密码 |
| 学生绑定失败 | 核对学生导入数据中的学号和姓名 |
| 教师看不到课程 | 当前轻量版为租户级权限，后续可加课程授权 |
| 需要回滚错误导入 | 数据采集 → 导入记录 → 删除 |
| 需要追查发布记录 | 审计留痕筛选 report.publish |
| 需要备份数据 | 备份 SQLite 和 uploads |
