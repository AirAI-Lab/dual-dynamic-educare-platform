# 常见问题与处理

## 1. 登录问题

### 忘记密码怎么办？

教师和学生联系管理员重置。管理员密码丢失时需由学校指定系统负责人通过本地数据库或运维流程处理。

### 提示登录过期怎么办？

重新登录。平台会话默认 12 小时。

### 修改密码后其他设备会退出吗？

会。修改密码后，当前账号其他会话失效。

## 2. 学生绑定问题

### 为什么绑定学号失败？

常见原因：

1. 学号输入错误；
2. 姓名与老师导入的数据不一致；
3. 老师尚未导入该学生；
4. 学生账号属于另一个学校租户。

### 学生能看到别人吗？

不能。学生只能看到本人已发布报告。

## 3. 导入问题

### 提示缺少分母怎么办？

检查表头是否包含：

```text
满分
课件总页数 / 共发放页数
公告总条数 / 共发布公告数
```

雨课堂原始导出通常会写在列名中，例如：

```text
总分(满分5740.0分)
观看总页数(共949页)
阅读公告数(共发布32个)
```

### 平均成绩导入了两次怎么办？

同一学生同一日期有唯一键，不会重复计算 ADG。如需清理记录：

```text
数据采集 → 导入记录 → 删除
```

如果是重复导入，系统会自动把数据挂到另一条导入记录。

### 即时数据导入了两次怎么办？

同样不会重复计算同一日期成绩。可在导入记录中删除多余记录。

## 4. 报表问题

### 为什么生成报表为空？

检查：

1. 是否选对课程；
2. 导入日期和生成日期是否一致；
3. 班级筛选是否过滤掉了所有学生；
4. 导入是否成功。

### 为什么无法发布？

报表必须先教师核定。状态流转：

```text
draft → reviewed → published
```

### 为什么导出前要确认？

平台执行低利害铁律。导出只用于教学诊断和个体支持，不得用于排名、评优、人事、薪酬或问责。

### 为什么没有排名？

平台制度性排除班级排名，成长报告只比较学生自身基线和趋势。

## 5. 预警与干预问题

### 为什么同一学生有两个预警？

这不是学生重复，而是两个预警项，例如：

```text
课件阅读系数红区
公告阅读系数红区
```

系统已合并为一行显示。

### 创建干预时为什么以前会失败？

早期页面没有携带真实学生 ID，导致后端收到 `student_id=0`。现已修复。请刷新页面后使用下拉干预表单。

### 心理辅导是否等于心理诊断？

不等于。系统中的“心理辅导转介”是教育支持动作，不生成诊断结论。

## 6. 权限问题

### 教师能看所有课程吗？

当前轻量版教师为学校/租户级权限。若需要“教师只能看自己课程”，下一阶段需增加课程授权表。

### 学生能看参数配置吗？

不能。学生端不显示参数配置和审计。

### 谁能看心理转介工单？

管理员可见全部，被分派教师可见自己的工单，未分派工单教师可见以便认领。
