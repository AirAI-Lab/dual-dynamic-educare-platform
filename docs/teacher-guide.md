# 教师使用手册

适用角色：任课教师、辅导员、课程助教  
适用版本：双动赋能双驱育心平台 轻量级 V2.1

## 1. 首次登录

1. 打开平台地址：

   ```text
   http://127.0.0.1:8000
   ```

2. 输入教师账号。
3. 首次登录后进入 **工作台 → 修改登录密码**。
4. 新密码至少 10 位。建议包含字母、数字和符号，不要使用工号或手机号。

如果忘记密码，请联系管理员在 **用户与角色** 中重置。

## 2. 教师端页面说明

| 页面 | 用途 |
|---|---|
| 工作台 | 查看课程、报表、预警、转介概况，修改密码 |
| 课程管理 | 创建课程、查看课程数据量 |
| 数据采集 | 导入历史 IDG 表、即时过程数据，管理导入记录 |
| 报表闭环 | 生成 IDG/ADG，教师核定，发布，撤回，导出 |
| 预警中心 | 查看成绩三色和系数预警，登记干预 |
| 成长画像 | 按学号查看学生自身成长曲线 |
| 量表与育心 | 管理量表、审批静默申请、处理心理转介工单 |
| 参数配置 | 查看阈值、权重、窗口等算法参数 |
| 使用手册 | 查看教师、学生、管理员手册 |

> 教师端没有班级排名接口。报表默认按班级和学号排序，用于个体支持，不是名次榜。

## 3. 创建课程

进入 **课程管理 → 新建课程**。

建议填写：

| 字段 | 示例 | 说明 |
|---|---|---|
| 课程名称 | 无机化学-25营养 | 建议包含课程和班级 |
| 课程代码 | WHXX-25YY | 同一学校内不能重复 |
| 数据源 | 雨课堂 | 用于记录数据来源 |
| 学年 | 2025-2026 | 便于归档 |

创建后系统会生成课程 ID。后续导入、生成报表都需要选择该课程。

## 4. 数据导入

### 4.1 推荐导入顺序

```text
1. 先导入历史平均动态成绩表
2. 再导入即时过程数据
3. 最后生成报表
```

原因是 ADG 需要历史 IDG 参与时间加权。如果没有历史表，也能生成报表，但第一期 ADG 会等于本期 IDG，成长趋势参考价值较弱。

### 4.2 导入历史平均动态成绩表

进入 **数据采集**。

| 设置 | 填写方法 |
|---|---|
| 课程 | 选择本课程 |
| 导入类型 | 历史 IDG 表 |
| 历史年份 | 填导出数据年份，例如 2025 |
| 班级/学号筛选 | 可填 `25营养`，留空则导入全部 |
| 文件 | 选择历史平均动态成绩 Excel |

系统会自动识别列名，例如：

```text
1001即时动态成绩
1003即时动态成绩
10月1日即时成绩
2025-10-01即时动态成绩
```

导入成功后会显示读取行数、导入周期数和导入记录数。

注意：

1. 历史表只导入历史 IDG，用于 ADG 计算。
2. 历史表不会覆盖过程性分子/分母证据。
3. 同一学生同一日期在数据库中有唯一键，重复导入不会重复计算。

### 4.3 导入即时过程数据

进入 **数据采集**。

| 设置 | 填写方法 |
|---|---|
| 课程 | 选择本课程 |
| 导入类型 | 即时过程数据 |
| 即时日期 | 例如 `2025-12-18` |
| 班级/学号筛选 | 例如 `25营养` |
| 文件 | 雨课堂导出的原始 Excel |

雨课堂原始工作簿不需要手工删除说明行。系统会自动选择第一个 **数据汇总** Sheet，并把第二行识别为表头。

系统会从表头提取分母，例如：

```text
总分(满分5740.0分)       → 课程总分 5740
观看总页数(共949页)      → 课件总页数 949
阅读公告数(共发布32个)   → 公告总条数 32
```

### 4.4 标准 CSV 模板

如暂无雨课堂原始表，可点击 **下载标准 CSV 模板**。

主要字段：

| 字段 | 含义 |
|---|---|
| 学生实得分 | 学生当前得分 |
| 课程总分 | 本期发放满分 |
| 有效阅读页数 | 已有效阅读页数 |
| 课件总页数 | 共发放页数 |
| 有效交互次数 | 有效互动次数 |
| 标准交互次数 | 标准互动次数 |
| 完整阅读公告条数 | 完整阅读的公告数 |
| 公告总条数 | 共发布公告数 |
| 已看视频秒数 / 视频总秒数 | 观测指标，不进入 IDG |
| 单页停留秒数 | 防刷课字段 |
| 全部页面完成秒数 | 防刷课字段 |
| 公告阅读停留秒数 | 防敷衍字段 |
| 公告图文加载完成 | 防敷衍字段 |

### 4.5 重复导入和删除

进入 **数据采集 → 导入记录**。

每条记录右侧有 **删除** 按钮。

| 场景 | 系统处理 |
|---|---|
| 删除重复历史导入 | 数据自动挂到另一条同课程历史导入 |
| 删除唯一历史导入 | 删除该次历史 IDG |
| 删除重复即时导入 | 数据自动挂到另一条同课程即时导入 |
| 删除唯一即时导入 | 删除该次过程观测数据 |

删除动作会写入审计。

## 5. 生成双动态报表

进入 **报表闭环 → 生成双动态报表**。

| 设置 | 填写方法 |
|---|---|
| 课程 | 选择课程 |
| 评价日期 | 与即时导入日期一致 |

点击 **计算 IDG / ADG**。

### 5.1 计算公式

课程百分得分：

```text
学生实得分 ÷ 课程总分 × 100
```

课件阅读系数：

```text
(有效页 ÷ 总页) × 0.6 + (有效交互 ÷ 标准交互) × 0.4
```

如果导出表没有交互分母，系统会降级为有效页单因子，并在报表中标记。

公告阅读系数：

```text
完整阅读公告条数 ÷ 公告总条数
```

即时动态成绩 IDG：

```text
课程百分得分 × 课件阅读系数 × 公告阅读系数
```

平均动态成绩 ADG：

```text
时间窗口内最近三个周期 IDG 加权平均
近 → 远：50% / 30% / 20%
```

不足三个周期时，系统按可用权重归一化。

### 5.2 三色规则

| 颜色 | 分数 |
|---|---|
| 绿 | ≥90 |
| 蓝 | 60–89.9 |
| 红 | <60 |

三色用于识别学习状态，不用于排名。

### 5.3 状态类型

| 状态 | 含义 | 建议形态 |
|---|---|---|
| 持续困难型 | 即时和平均都低 | 救护车：教师一对一，必要时转介 |
| 进步改善型 | 即时改善但平均仍低 | 导航仪：肯定进步趋势 |
| 短期波动型 | 即时下降但平均尚可 | 导航仪：波动提醒 |
| 稳定达标型 | 两项达到蓝区以上 | 导航仪：稳定达标鼓励 |
| 成绩领跑型 | 两项达到绿区 | 导航仪：荣誉激励 |

## 6. 教师核定与发布

报表生成后状态为 **draft（待核定）**。

### 6.1 核定前检查清单

发布前建议逐项检查：

1. 课程和评价日期是否正确。
2. 学生人数是否符合本次教学班。
3. 总分、总页数、公告总数等分母是否合理。
4. 异常高值或异常低值是否有原因。
5. 红区学生是否需要先核对数据。
6. 是否存在大规模系数异常，可能是导入模板问题。
7. 是否确认本次用途为低利害教学改进。

### 6.2 核定

点击 **教师核定**，确认提示后完成。状态变为：

```text
reviewed（已核定）
```

### 6.3 发布

点击 **发布学生端**。

发布后：

1. 学生登录后可查看本人数据。
2. 后端拒绝发布未核定报表。
3. 重复点击发布是幂等操作。
4. 发布、核定、撤回都会写入审计。

### 6.4 撤回

发布后 24 小时内可撤回。

点击 **24小时内撤回**，填写撤回原因。撤回后学生端不再可见。

超过 24 小时不能再撤回，如确有错误请联系管理员按数据修正流程处理并留痕。

### 6.5 导出

点击 **低利害导出**。

导出前必须确认：

```text
仅用于低利害诊断与个体支持
不用于排名、评优、人事、薪酬或问责
```

导出文件默认按班级和学号排序，不按成绩排序。

## 7. 看懂报表列

| 列 | 怎么理解 |
|---|---|
| 课程% | 学生实得分的百分化 |
| 课件系数 | 有效阅读与有效交互的综合系数 |
| 公告系数 | 公告完整阅读比例 |
| 视频 | 观测系数，<1 标红，不进 IDG |
| 互动 | 观测系数，<1 标红，不进 IDG |
| IDG | 本期即时动态成绩 |
| ADG | 时间窗口内平均动态成绩 |
| 分子/分母 | 每个系数的来源证据 |
| 预警 | 成绩三色之外的过程预警 |

查看学生时，建议先看分子/分母，再看分数。例如：

```text
公告 12/32 → 公告阅读系数低
课件 300/949 → 课件阅读任务欠账较多
得分 80/100 → 课程任务本身尚可
```

## 8. 预警中心

进入 **预警中心**。

### 8.1 两套预警不要混用

成绩三色：

```text
绿 ≥90
蓝 60–89.9
红 <60
```

系数预警：

```text
红 <0.50
蓝 <0.80
```

视频和互动是观测指标：

```text
<1.00 标红
但不进入 IDG
```

### 8.2 合并显示

同一学生同一份报表中可能同时出现：

```text
课件阅读系数红区
公告阅读系数红区
```

系统会合并为一行，在“预警项”列显示多个标签，避免看起来像重复学生。

### 8.3 前置预警

以下情况会提示 48 小时内介入：

1. 同一系数连续 3 次低于 0.80。
2. 系数较上一周期骤降超过 0.30。

## 9. 登记干预

在预警中心或报表详情点击 **登记干预**。

系统提供下拉选项，不再需要手工填写干预类别。

| 类型 | 适用场景 |
|---|---|
| 导航仪 · 学习提醒 | 轻度漏读、短期波动 |
| 导航仪 · 最小行动目标 | 学生需要一个小步行动 |
| 导航仪 · 成长趋势反馈 | 肯定进步或解释趋势 |
| 救护车 · 教师一对一 | 持续困难、需要深入沟通 |
| 救护车 · 心理辅导转介 | 存在心理支持需求 |

填写具体安排后保存。

如勾选 **同步创建 2 小时心理转介工单**，系统会同时生成转介工单。

所有干预均写入审计。

## 10. 心理转介工单

进入 **量表与育心 → 心理转介工单**。

### 10.1 创建

| 字段 | 填写方法 |
|---|---|
| 学生学号 | 例如 `S20240001` |
| 原因 | 简要说明，不写无关敏感细节 |
| 分派给 | 选择教师或管理员 |
| 外部处理人 | 学校心理中心、辅导员等，可留空 |

默认分派给当前登录教师。

### 10.2 查看权限

| 角色 | 可见范围 |
|---|---|
| 管理员 | 全部工单 |
| 被分派教师 | 自己的工单 |
| 其他教师 | 可见未分派工单，便于认领 |
| 学生 | 不可见 |

### 10.3 处理状态

| 状态 | 含义 |
|---|---|
| open | 待处理 |
| reported | 已上报学校心理中心或辅导员 |
| completed | 已完成 |
| escalated | 超时自动升级 |

处理时填写 **处理留痕**，点击保存。超过 2 小时未处理的工单会自动升级。

## 11. 量表与静默通道

### 11.1 量表

教师可创建量表：

1. 标题。
2. 说明。
3. 状态：草稿或发布。
4. 题目 JSON。

每题可配置：

| 属性 | 说明 |
|---|---|
| stem | 题干 |
| options | 选项 |
| reverse_scoring | 是否反向计分 |
| crisis_operator | 危机触发比较符 |
| crisis_value | 危机触发阈值 |

正式量表条目应由学校按版权和伦理要求导入。系统不内置 CD-RISC-25 全部条目。

### 11.2 学生提交结果

学生提交后：

1. 学生不会看到量表分数。
2. 量表结果不进入成绩报表。
3. 教师可在授权工作流中查看。
4. 触发危机规则时自动创建 2 小时转介工单。

### 11.3 静默申请

学生可申请静默，教师看到后点击批准或拒绝。批准后，该学生不再接收非必要公告提醒。

## 12. 学生如何查看已发布报告

请向学生说明：

1. 使用学生账号登录。
2. 首次登录绑定学号和姓名。
3. 进入 **我的成长报告**。
4. 只能看到本人已发布数据。

如需全班学生使用，请管理员在 **用户与角色** 中创建账号。建议账号名使用学号。

## 13. 教师常见问题

| 问题 | 原因与处理 |
|---|---|
| 找不到课程 | 确认课程未归档，且账号属于同一学校租户 |
| 导入后生成报表为空 | 检查导入日期和生成日期是否一致 |
| 提示缺少分母 | 检查表头是否包含满分、总页数、公告总数 |
| 学生出现两次预警 | 原为多个预警项，现已合并显示 |
| 无法发布 | 报表未核定；先教师核定再发布 |
| 干预保存失败 | 刷新页面后使用新版下拉干预表单 |
| 学生看不到报表 | 确认报表已发布，学生已绑定正确学号和姓名 |
| 想删除重复导入 | 数据采集 → 导入记录 → 删除 |
