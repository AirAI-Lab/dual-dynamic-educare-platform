# 学生使用手册

适用角色：学生  
适用版本：双动赋能双驱育心平台 轻量级 V2.1

## 1. 这个平台是用来做什么的？

本平台不是给你排名次，也不是给你贴标签。

它主要帮助你看到：

1. 最近学习过程是否稳定；
2. 哪些学习任务还没有完成；
3. 自己相对过去是否有成长；
4. 需要老师帮助时，如何申请支持。

请记住：

```text
动态成绩是路标，不是判决书。
```

## 2. 登录

1. 打开老师提供的平台地址。
2. 输入学生账号和密码。
3. 首次登录后，请到 **我的工作台 → 修改登录密码**。

如果无法登录：

1. 检查账号密码是否输入正确；
2. 联系老师或管理员确认账号已创建；
3. 忘记密码时请联系管理员重置。

## 3. 首次绑定学号

第一次登录后，系统需要把你的账号和班级数据绑定。

进入 **我的工作台 → 绑定学号**：

| 字段 | 填写 |
|---|---|
| 学号 | 填正式学号，例如 `S20240001` |
| 姓名 | 填真实姓名 |

注意：

1. 学号和姓名必须与老师导入的数据一致；
2. 不一致时系统会拒绝绑定；
3. 绑定成功后只能查看自己的数据。

## 4. 查看我的成长报告

绑定成功后，进入：

```text
我的成长报告
```

可以看到：

| 项目 | 含义 |
|---|---|
| 课程百分得分 | 课程任务得分情况 |
| 课件阅读系数 | 课件阅读和互动完成情况 |
| 公告阅读系数 | 课程公告阅读情况 |
| IDG | 本期即时动态成绩 |
| ADG | 一段时间内的平均动态成绩 |
| 三色 | 绿、蓝、红三种状态提示 |
| 成长指引 | 下一步可以采取的小行动 |

如果报告列表为空，可能是：

1. 老师还没有发布报告；
2. 你尚未绑定学号；
3. 你绑定的学号不在本课程数据中。

## 5. 如何理解三色？

| 颜色 | 分数 | 含义 |
|---|---|---|
| 绿 | ≥90 | 过程投入很完整 |
| 蓝 | 60–89.9 | 基本达标，但还有可补齐的地方 |
| 红 | <60 | 近期任务缺口较大，建议尽快行动 |

三色不是能力评价，也不是和别人比较，只提示最近一段时间的学习过程状态。

## 6. 如何理解 IDG 和 ADG？

### IDG：即时动态成绩

反映本期：

```text
课程任务得分 × 课件阅读系数 × 公告阅读系数
```

如果某一项没有完成，IDG 会明显下降。这是为了提醒你尽快补齐关键任务。

### ADG：平均动态成绩

反映一段时间内的整体趋势。

一次下降不代表失败；如果 ADG 稳定，说明整体过程仍然平稳。

## 7. 分子/分母怎么看？

报表中的证据会显示类似：

```text
课件 300/949
公告 12/32
得分 80/100
```

含义：

| 证据 | 如何判断 |
|---|---|
| 课件 300/949 | 已读 300 页，共发放 949 页 |
| 公告 12/32 | 完整阅读 12 条，共 32 条 |
| 得分 80/100 | 当前课程任务得 80 分 |

## 8. 分数较低时可以怎么做？

### 课程百分得分低

可以检查：

1. 是否有课件习题未完成；
2. 是否有试卷未提交；
3. 是否需要重做错题；
4. 是否需要向老师请教薄弱知识点。

### 课件阅读系数低

可以这样做：

1. 先补未读课件；
2. 每天课后浏览当天新课件；
3. 标出 1–2 个不确定的概念；
4. 下次课带着问题听讲。

### 公告阅读系数低

可以这样做：

1. 设置每天固定提醒；
2. 睡前查看课程通知；
3. 重点看作业、考试、实验安排；
4. 不确定时问同学或老师。

### 给自己一个最小行动目标

不建议一次制定很大的计划，可以先用：

```text
今天课后，我把今天讲义的 10 页课件看完，
并标出 2 个不懂的概念。
```

完成后，再设定下一个小目标。

## 9. 成长曲线

进入 **成长曲线**。

你可以看到：

1. 起点/基线；
2. 近期 IDG 变化；
3. 60 分和 90 分参考线。

系统不会显示班级排名、你的名次或其他同学成绩。你只需要和过去的自己比较。

## 10. 量表填写

如果老师发布量表，进入 **量表与静默通道**。

填写规则：

1. 按真实感受作答；
2. 不需要填写不必要的敏感个人信息；
3. 提交后系统不会向你展示心理分数；
4. 量表结果不进入成绩。

如果你目前遇到明显困难，请优先直接联系老师、辅导员或学校心理中心。量表不能替代紧急求助。

## 11. 申请静默

如果你希望暂时减少公告提醒，可以填写静默申请。

进入 **量表与静默通道 → 静默通道申请**。

可以简单填写：

```text
近期希望减少公告提醒
```

不需要详细解释隐私原因。老师审批后，你会进入静默状态。

## 12. 隐私与安全

平台遵守以下原则：

1. 你只能看到自己的数据；
2. 系统不提供班级排名；
3. 量表结果不进入成绩；
4. 系统不向学生发布心理评价结果；
5. 心理危机处置由学校心理健康中心负责。

如果你感到情绪困扰明显、难以自控，或出现安全问题，请立即联系辅导员、学校心理中心、家长或信任的老师。

## 13. 学生常见问题

| 问题 | 处理方法 |
|---|---|
| 登录不上 | 检查账号密码，必要时联系管理员 |
| 绑定失败 | 确认学号和姓名与学校数据一致 |
| 看不到报告 | 等老师发布，或确认已绑定学号 |
| 报告为红标 | 先看分子/分母，补做最低成本任务 |
| 报告突然下降 | 检查公告和课件是否遗漏，不要自我否定 |
| 想减少提醒 | 提交静默申请 |
| 感到压力较大 | 主动联系老师、辅导员或心理中心 |
